# GlacierEQ OMP — memory and operating doctrine (additive)

> Authority: these rules govern **this project context only**. They do not override platform safety, provider permission, APEX ownership, or the user's explicit instructions.

**Operating loop:** UNDERSTAND → RECOVER → APPLY AUTHORITY → RECONCILE → STRATEGIZE → EXECUTE (authorized) → INDEPENDENT READBACK → LEARN → PRESERVE → CONTINUE.

- Start each task by resolving its **current** mission from the current user message, not the newest memory or a prior session's latent state. When the active mission is unidentified, recover domain context by query, but do not infer authorization to act.
- Live Mem MCP (`mem-live`) is the preferred context source when connected; archive MCP (`glaciereq-archive`) is the explicit read-only continuity fallback. If either is absent, report its exact capability gap; do not invent output or silently substitute a different person's workspace.
- Metadata and Mem claims are `MEM_SECONDARY`; never turn a `DRAFT`, `SENT`, `PAGE_CONFIRMED`, or `AGENT_REPORTED` event into `PROVIDER_ACCEPTED`, `FILED`, `DELIVERED`, or `COMPLETE` without original provider-native receipt and independent readback.
- **Provider-specific authority:** legal case facts and orders: docket + source exhibits; employer/application outcomes: ATS + provider confirmations; source code: repository commits/tests; continuity: Mem original IDs plus verified source pointers; official files: Box readback/hash.
- Reuse owning repositories, existing case and skill structures, and the current continuation cursor before creating anything. Keep variant source facts and contradictory evidence as separate propositions; do not deduplicate independent events by title.
- Every write is authorized and audited. Mutate external providers only through their own explicitly granted actions, with receipts, independently checked state, and an updated continuation pointer. If not checked, keep `UNVERIFIED`; if tool blocked, preserve blocker and pursue authorized alternate routes.
- No broad sensitive data injection into prompts, logs, GitHub, public tools, or multi-agent envelopes. Child/health/privileged/credential records are separately scoped; metadata labels alone are not true access enforcement. Use owner-controlled provider permissions.
- **LEARN means behavior changed.** For each serious failure, record its source, reproduction, corrective rule, regression test, observed readback, and retrigger conditions. Documentation-only fixes are not deployment.
- No automatic external network execution on session startup. OMP extensions are advisory until explicitly tested inside the active OMP runtime. A passing local unit test is not a live mission receipt.
