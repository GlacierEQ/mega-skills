# Mega Skill Release Checklist

1. Confirm that each referenced Combo ID resolves in the canonical registry.
2. Confirm that the candidate adds at least two Combos and a distinct mission-level artifact.
3. Confirm `capability-readiness` is a conditional route and all advanced route prerequisites remain explicit.
4. Confirm no external effect, schedule, polling process, deployment, or repository mutation is implied without a separately approved route.
5. Confirm `MEGA.md`, registry entry, tests, version, and durable-state list agree.
6. Run the hierarchy validator and full regression suite; preserve the exact result.
7. Review the diff for duplicated procedures, unsupported claims, unregistered IDs, and missing non-goals.
8. Commit and push only under the user’s repository-change authorization; report the commit and remaining limitations.
