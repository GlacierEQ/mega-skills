# APEX Forensic Litigation Sentinel

## Mission

Autonomous legal prosecution and investigative warfare: dissects judicial dockets, aligns minute-by-minute transcripts against official records, detects 39-second impossibilities, and outputs verified impeachment traps for state and federal courts.

## Compounding structure

| Mandatory route | Conditional route | What the Mega layer adds |
|---|---|---|
| `forensic-docket-intelligence` | `capability-readiness` | Coordinates end-to-end execution of forensic-docket-intelligence with mission-level state gates. |
| `long-horizon-core` | `court-evidence-compiler` | Dynamically activates court-evidence-compiler based on mission requirements. |
| `long-horizon-core` | `voice-evidence-authenticator` | Dynamically activates voice-evidence-authenticator based on mission requirements. |
| `long-horizon-core` | `automation-control` | Dynamically activates automation-control based on mission requirements. |

## Route algorithm

1. Initialize mission state with `long-horizon-core` and load mission boundary parameters.
2. Evaluate `capability-readiness` for all required and conditional combo routes.
3. Execute primary pipeline via `forensic-docket-intelligence`.
4. Conditionally dispatch specialist combos based on runtime risk flags and telemetry.
5. Compile final verified deliverable into `FORENSIC_LITIGATION_SENTINEL_RECORD.md` and persist immutable state.

## Durable state

`MISSION.md, ROADMAP.md, CONTEXT.md, EVIDENCE.md, HANDOFF.md` maintain durable mission state across sprints and server restarts.
