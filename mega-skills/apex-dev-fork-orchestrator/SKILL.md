# APEX Dev Fork Orchestrator Mega Skill

## Mission

Coordinate automated weekly synchronization, overlay layer shielding, and regression test gatekeeping across all 513 repository forks in `GlacierEQ`.

## Compounding structure

| Mandatory route | Conditional route | What the Mega layer adds |
|---|---|---|
| `long-horizon-core` | `upstream-fork-harmonization` when repository forks must be synchronized with upstream | Coordinates multi-fork batch synchronization, overlay layer shielding, and automated remote pushes. |
| `long-horizon-core` | `automation-control` when weekly scheduled synchronization workflows are executed | Manages recurring GitHub Actions workflows and automated failure alerting. |

## Route algorithm

1. Begin the fork synchronization campaign with `long-horizon-core` and enumerate target forks.
2. Select `upstream-fork-harmonization` for each fork in the active batch.
3. Verify that custom overlay layers (`extensions/`, `sidecars/`, `plugins/`) remain 100% untouched.
4. Execute full local regression test suites to guarantee zero regression before push.
5. Select `automation-control` to verify and configure recurring synchronization cron triggers.
6. Reconcile upstream commit ranges, test receipts, and push SHAs into `EVIDENCE.md` and emit final audit package.

## Durable state

`MISSION.md`, `ROADMAP.md`, `CONTEXT.md`, `EVIDENCE.md`, and `HANDOFF.md` maintain upstream synchronization state across the 513-fork estate.
