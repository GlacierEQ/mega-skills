# Strong-Smart Execution Stack

## Mission

Compose operator authority, measurable power-fit routing, maximum useful execution density, evidence discipline, orchestration, and durable handoff into one enforceable mission stack.

## Required members

1. `casey-operator-execution-kernel` — operator intent, semantic locks, corrections, and authority.
2. `strong-smart-routing-kernel` — measurable power-fit routing.
3. `power-skill` — strongest relevant capability composition.
4. `make-it-heavy` — maximum useful engineering and reasoning density.
5. `epistemic-gate` — typed claims and proof floors.
6. `quality-gate` — tested acceptance evidence.
7. `handoff-record` — receipts, alternatives, and continuation state.

## Ordered execution

`INTENT → LOCKS → POWER-FIT → COMPOSE → EXECUTE → ADVERSARIAL VERIFY → READBACK → PRESERVE → HANDOFF`

Emit `STRONG_SMART_EXECUTION_RECEIPT.json` containing mission intent, selected route, rejected alternatives, gate results, evidence locators, provider readback, and continuation state.

## Non-negotiable gates

- Capability is maximized only inside authorized scope.
- Consequential external effects remain approval-gated.
- Strong means mission-complete and resilient, not gratuitously complicated.
- Smart means evidence-weighted, coherent, and strategically leveraged, not tool-count theater.
- `GENERATED != EXECUTED != VERIFIED`.
