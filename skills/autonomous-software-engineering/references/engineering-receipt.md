# Autonomous Engineering Delivery Receipt

Use this receipt after an end-to-end engineering mission. Redact secrets and sensitive data before sharing.

| Field | Value |
|---|---|
| Mission ID and owner | `<stable ID, requester, technical owner>` |
| Repository and commit | `<repo>@<commit>` |
| Objective and acceptance | `<outcome, scope, non-goals, measurable criteria>` |
| Pipeline route | `<stages and specialized skills used>` |
| Architecture evidence | `<graph, layering, cycle, and boundary result>` |
| Implementation | `<changed files, transformations, compatibility notes>` |
| Tests and coverage | `<focused/full tests, coverage, mutation or fault evidence>` |
| Security | `<scanners, findings, remediations, exceptions, residual risk>` |
| Performance | `<baseline/post-change protocol, metrics, variance, budget>` |
| Tower evidence | `<not applicable, or preflight → source-of-truth → proof → validate → generate → test → build → integrity → receipt>` |
| Quality gate | `<commands, results, blockers, reviewer>` |
| Handoffs | `<artifacts, receivers, acceptance tests, unresolved risks>` |
| Approval boundary | `<what was authorized and what still requires confirmation>` |
| Rollback | `<revert commit, feature flag, restoration, or recovery command>` |
| Release decision | `<pass, block, escalate, or rolled back>` |
| Observations | `<flaky tests, false positives, drift, follow-up work>` |
| Next action | `<specific owner and close condition>` |
