# Test Generation and Coverage Receipt

Use this template after generating or strengthening tests. Replace every placeholder and attach machine-readable coverage output when available.

| Field | Value |
|---|---|
| Repository and commit | `<repo>@<commit>` |
| Quality target | `<modules, behaviors, risk class, acceptance criteria>` |
| Framework and tools | `<test runner, coverage tool, generator, versions>` |
| Baseline | `<tests, line/branch/function coverage, runtime, known flakes>` |
| Generated / edited / skipped files | `<counts and notable paths>` |
| Test categories | `<regression, contract, boundary, property, integration, concurrency>` |
| Final results | `<focused tests, full suite, build, runtime>` |
| Coverage | `<metric, included/excluded scope, before → after, threshold>` |
| Enforcement | `<command, fail-closed behavior, CI/policy change>` |
| Mutation or fault injection | `<tool, scope, survivors, follow-up>` |
| Tower route | `<not applicable, or preflight → registry → exhibits → proof → validate → generate → test → build → integrity → receipt>` |
| Evidence state | `<declared state and supporting artifact>` |
| Flakes / skips / limitations | `<known instability or untested risk>` |
| Exception | `<owner, reason, expiry; write “none” when absent>` |
| Rollback | `<revert commit, patch, or restoration command>` |
| Next action | `<merge, review, retry, or remediation>` |
