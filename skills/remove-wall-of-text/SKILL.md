# remove-wall-of-text

## Goal
Cut filler · keep facts · tables for parallels · no loss of decisions/paths.

## Method
1. Lead with outcome (1 sentence).
2. Bullets/tables for everything parallel.
3. Drop: “Let me…”, restatements, process theater, duplicate paths.
4. Keep: decisions, file paths, commands, numbers, next action.
5. Target: ≤40% of original length when possible without losing truth.

## Never strip
- Code blocks needed to act
- Exact error messages
- Legal/evidence hashes
- Measured metrics

## Pair with
`token-saver` · pure_pointer for large bodies · `/compact` when session heavy
