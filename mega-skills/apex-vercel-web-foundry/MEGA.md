# APEX Vercel Web Foundry

## Mission

Full-stack modern web engineering foundry spanning Next.js, Turbopack, edge functions, serverless KV storage, and continuous Vercel deployment.

## Compounding structure

- Required combos: `long-horizon-core`, `vercel-fullstack-deployment`, `web-build-foundation`
- Conditional combos: `capability-readiness`, `closed-loop-code-repair`

## Execution protocol

1. Initialize `MISSION.md` through `HANDOFF.md` in the active execution workspace.
2. Execute required combos in deterministic dependency order.
3. Validate all intermediate evidence hashes and record telemetry in `EVIDENCE.md`.
4. Synthesize final mission deliverable `VERCEL_WEB_FOUNDRY_RECORD.md`.

## Durable state files

- `MISSION.md`
- `ROADMAP.md`
- `EVIDENCE.md`
- `CONTEXT.md`
- `HANDOFF.md`
- `VERCEL_WEB_FOUNDRY_RECORD.md`

## Cognitive firewall

- Mode: `read_only`
- Fail closed: `true`
- Allowed actions: `read_repository`, `run_local_tests`, `write_run_artifacts`, `emit_receipt`
- Forbidden actions: `external_mutation`, `network_send`, `file_submission`, `deletion`, `deployment`, `merge`, `credential_access`, `legal_filing`, `autonomous_legal_decision`, `execute_unknown_program`

## Human control points

- `approve_production_release`
- `escalate_critical_anomalies`

## Output contract

Produce `VERCEL_WEB_FOUNDRY_RECORD.md` upon mission completion.

## Local validation

Turbopack build, edge function routes, and responsive UI layout tests pass 100%.

## Non-goals

Destructive database drops or unauthorized live DNS alterations
