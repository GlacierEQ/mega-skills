# Source-Bound Correspondence Workflow (candidate v0.1.0)

Owning system: GlacierEQ/mega-skills; source truth belongs to connected Gmail and other providers; APEX/Context First owns mission boot and admission; Linear holds the current execution graph. This is a documented candidate workflow, not a deployed background service.

## Account routing

Resolve current authenticated sender from the existing private Linear connector/misson policy (HI-158). Legal/personal Casey, beneficiary Cherry first-party matters, and Casey career applications use separate specified accounts. Preserve historic threads already in other accounts and never make duplicate applications simply to switch sender address. First-party signature, consent, protected records and representation permissions require their own source proof.

## Dependency graph

1. Existing long-horizon-core recovers mission, exact case identity, restrictions, established receipts, correction and context.
2. correspondence-identity-gate checks sender, beneficiary, connector, first-party authority and privacy.
3. provider-thread-forensics recovers chronological provider-native evidence, including DRAFT vs SENT vs ACK and newest reply.
4. linear-frontier-deduplicator locates existing owner by exact provider/action identity and retires stale sends.
5. jurisdiction-authority-citation-check verifies primary law and actual provider response duties, not abstract assumptions.
6. adverse-outcome-remedy-router maps approvals, partial results, denials and silence to lawful review options.
7. precision-provider-email produces a decision-ready draft; external transmission remains authorization-gated.
8. receipt-provenance-continuation confirms the actual provider effect and refreshes the same Linear issue, preserving durable continuation.

## Provider-stage vocabulary

| Stage | Meaning | Next step |
| --- | --- | --- |
| DRAFT | Unsent writing | Review; no delivery claim |
| SENT | Source provider shows sent from authenticated account | Wait for other-side acknowledgment or documented response |
| ACKNOWLEDGED | Custodian confirms received | Track assignment/scope/time and avoid repetition |
| PROCESSING | Review or investigation in progress | Await decision and advance independent fronts |
| PRODUCED_PARTIAL | Some responsive categories obtained | Authenticate and pursue missing categories |
| PRODUCED_FULL | All applicable categories returned | Verify content and concrete requested remedy |
| DENIED | Written adverse determination | Preserve reasons/date, check actual applicable review and appeals |
| AMBIGUOUS | Send/effect unresolved | Obtain source-native status before any retry |

## Authority anchors (must be checked for each case)

* Hawaii state-agency government-record requests: HRS ch. 92F, HAR 2-71-13 (and notice/extension/fee exceptions), OIP administrative appeal under HRS 92F-15.5; judicial remedies under applicable HRS 92F-15. Consult https://ags.hawaii.gov/oip/uipa-rules/ and https://ags.hawaii.gov/oip/guide-to-oip-appeals/.
* Federal FOIA requests to covered agencies: 5 USC 552(a)(6), agency FOIA regulations and exemptions, segregability, FOIA public liaison and actual adverse-appeal notice. Consult https://www.justice.gov/oip/freedom-information-act-5-usc-552.
* Hawai‘i CSEA procedural information: https://ag.hawaii.gov/csea/order-processing/ . Distinguish original order/modification/termination service and hearing request periods; do not assume they use one uniform clock.
* None of the above automatically governs Family Court filings, federal criminal defense disclosure, Navy IG confidentiality or private employer correspondence. Confirm forum-specific rules separately.

## Every response must advance the observable human outcome

Grant → verify implementation; partial grant → reconcile omissions; denial → identify exact decision-maker/reasons/review route and preserve evidence; silence → verify due-date rule and follow up appropriately; ambiguous → reconcile original source and authorize no repeat. This is not a guaranteed win engine. A lawful adverse response provides a testable record, not proof of misconduct.

## Negative-path acceptance

* A Cherry investigator reply in Cherry's mailbox must override a stale 'no response in Casey's mailbox' statement.
* An existing agency letter sent today must block sending its duplicate tomorrow.
* A saved draft must never be counted as sent or filed.
* An agency acknowledgment must never prove case outcome.
* A third-party response request cannot override first-party consent or CUI restrictions.
* A denied FOIA/UIPA request can never be automatically mapped to judicial victory.
* Prior reports and applications cannot be repeated when verified completion receipts exist.
* A cold start with only Linear owning issue and provider pointers must select the correct next lawful action.
