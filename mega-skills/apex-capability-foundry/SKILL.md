# APEX Capability Foundry Mega Skill

## Mission

Convert evidence from repeated work into a review-ready, registered skill-system increment. This Mega Skill coordinates discovery, readiness, evidence synthesis, reusable-skill authoring, and release verification. It does not promote an unsupported concept or push a repository change without user authorization.

## Compounding structure

| Mandatory route | Conditional route | What the Mega layer adds |
|---|---|---|
| `long-horizon-core` | `recon-and-map` when repository roles or ownership are unclear | Maps the smallest valid home and change boundary. |
| `long-horizon-core` | `capability-readiness` before using a specialized capability | Records whether required tools, examples, and validation paths are actually available. |
| `long-horizon-core` | `signal-to-decision-loop` when evidence may not justify a new capability | Separates observed need from the decision to build. |
| `long-horizon-core` | `evidence-to-evolution-loop` then `skill-forge` after review | Converts repeated evidence into a bounded reusable package and governed release. |

## Route algorithm

1. Start `long-horizon-core` and define the target repository, ownership, user outcome, non-goals, compatibility constraints, and release authority.
2. Use `recon-and-map` if role, provenance, or source-of-truth uncertainty remains.
3. Use `capability-readiness` to verify that examples, dependencies, validation tools, and required authority exist for the candidate scope.
4. Use `signal-to-decision-loop` to decide whether the observed pattern merits a lower-layer Skill, a Combo, a Mega, or no new package.
5. Use `evidence-to-evolution-loop` to create `CAPABILITY_EVOLUTION_PROPOSAL.md`, then invoke `skill-forge` only after the proposal is accepted for implementation.
6. Integrate registry, test, validation, compatibility, release, and handoff evidence into `CAPABILITY_FOUNDRY_MISSION_RECORD.md`.

## Durable state

`MISSION.md`, `ROADMAP.md`, `CONTEXT.md`, `EVIDENCE.md`, and `HANDOFF.md` are the source of truth. The final mission artifact is `CAPABILITY_FOUNDRY_MISSION_RECORD.md`.
