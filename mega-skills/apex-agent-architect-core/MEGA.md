# APEX Agent Architect Core

## Mission

End-to-end AI agent design, multi-agent mesh topology synthesis, dynamic tool generation, bounded fan-out, and contradiction-preserving dialectic swarm synthesis.

## Compounding structure

- Required combos: `long-horizon-core`, `multi-agent-orchestration-mesh`, `autonomous-agent-foundry`
- Conditional combos: `capability-readiness`

## Execution protocol

1. Initialize `MISSION.md` through `HANDOFF.md` in the active execution workspace.
2. Execute required combos in deterministic dependency order.
3. Validate all intermediate evidence hashes and record telemetry in `EVIDENCE.md`.
4. Synthesize final mission deliverable `AGENT_ARCHITECT_RECORD.md`.

## Durable state files

- `MISSION.md`
- `ROADMAP.md`
- `EVIDENCE.md`
- `CONTEXT.md`
- `HANDOFF.md`
- `AGENT_ARCHITECT_RECORD.md`

## Cognitive firewall

- Mode: `read_only`
- Fail closed: `true`
- Allowed actions: `read_repository`, `run_local_tests`, `write_run_artifacts`, `emit_receipt`
- Forbidden actions: `external_mutation`, `network_send`, `file_submission`, `deletion`, `deployment`, `merge`, `credential_access`, `legal_filing`, `autonomous_legal_decision`, `execute_unknown_program`

## Human control points

- `approve_production_release`
- `escalate_critical_anomalies`

## Output contract

Produce `AGENT_ARCHITECT_RECORD.md` upon mission completion.

## Local validation

Multi-agent synthesis preserves unresolved dissent, promotes only evidence-supported convergence, and emits zero hallucinated tool calls.

## Non-goals

Unbounded recursive agent spawning without supervisor depth bounds
