# Hidden-Harm Counter-Wave

## Operator doctrine (solidified)

Hidden-harm skills are the **counter-wave**. They go on everything. They are designed to **dynamically counter-engineer other hidden harms** — including harms created by “fixes,” summaries, fallbacks, status labels, and prior counter-engineering itself.

This is not a permission ladder and not a new product. It is cross-cutting execution hygiene under Operator sovereignty.

## Always-on composition

Before material execution, mutation, merge, connector write, memory projection, case elevation, or completion claim:

1. Load `integrations/hidden-harm-skill-matrix.json`
2. Select the **narrowest** specialist(s) for the work unit
3. Always keep `hidden-harm-cross-domain` as remainder cover when any risk is uncovered
4. Run the shared pattern:  
   `DETECT LOSS -> NAME LOST DIMENSION -> PRESERVE STRONGER STATE -> ROUTE AROUND -> VERIFY -> PERSIST`
5. **Recursive pass:** after the remediation plan exists, ask what *new* silent loss that plan would create (false verification, compression, dual doors, peak language, bureaucracy capture). Counter those too.
6. Persist a short receipt (lost dimension, route taken, verification scope) into the work lineage

## Specialist map

| Domain | Skill |
|---|---|
| GitHub / branches / PRs / CI / release / deploy | `hidden-harm-github` |
| Context / memory / summaries / continuity | `hidden-harm-context` |
| Connectors / plugins / MCP / providers | `hidden-harm-connectors` |
| Legal / evidence / casebuilding | `hidden-harm-casebuild` |
| Everything else / remainder risk | `hidden-harm-cross-domain` |

Compose multiple when a unit crosses domains. Cross-domain alone is never an excuse to skip a better specialist.

## Dynamic counter-engineering (meta-harms)

Watch for harms that wear the costume of help:

- **Fix theater** — a scrub/doc/PR that leaves the false path live elsewhere
- **Verification capture** — proving forever after enough truth exists to act
- **Convenience centralization** — one easy store becomes “the truth”
- **Bureaucracy capture** — hidden-harm process displacing the Operator objective
- **Peak language** — “restored / complete / wired” while dark components remain
- **Dual surfaces** — two front doors, two vaults, two doctrines without Operator pick
- **Correction resurrection** — old assistant interpretation returns after Operator corrected it

When a remediation introduces any of these, reject or redesign before execute.

## Executable router

`scripts/hidden_harm_counter_wave.py` selects specialists from work tags/text and returns a composition plan + recursive checklist. Prefer that over ad-hoc guessing.

## Success

The estate becomes harder to accidentally weaken. Success is a stronger living continuation with protected dimensions preserved — not a longer audit checklist.
