# Anthropic Applied AI Career Pipeline

## Objective

Turn the operator's real engineering work into a continuously updated, evidence-bound candidate package for Anthropic Applied AI roles, with **Applied AI Architect** as the primary role target and **Forward Deployed AI Architect** as the professional operating identity.

## Durable flow

`INHERIT → RETRIEVE → VERIFY → MAP → GAP-ANALYZE → BUILD → PROVE → PROJECT → APPLY → LEARN → REWEIGHT`

The pipeline must never collapse architecture, prototype, simulation, or plan into a production claim.

## Sources

The mission may consume verified repository state, Job App Helix outputs, portfolio artifacts, prior target research, public role requirements, and operator-provided firsthand context. Each outward claim must retain source lineage and an epistemic state.

## Outputs

- `target-role.json` — versioned company/role contract.
- `target-competency-map.json` — normalized competency/evidence contract.
- `pipeline-execution-manifest.json` — durable execution receipt.
- evidence ledger — claim → artifact → verification → state.
- projections — LinkedIn, résumé, portfolio, interview, and application packages generated from the same evidence graph.

## Invariants

1. Generic pipeline machinery remains company-agnostic.
2. Anthropic-specific requirements live in target data and mission composition.
3. Public claims require evidence lineage.
4. Gaps become build targets, not invented accomplishments.
5. Every completed stage leaves a resumable artifact or a verifiable receipt.
6. New evidence reweights the next highest-impact action rather than restarting the mission.
