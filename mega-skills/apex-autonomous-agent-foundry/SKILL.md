# APEX Autonomous Agent Foundry

## Mission

End-to-end agent manufacturing mission control: orchestrates multi-agent system architecture, persistent memory topology, statistical evaluation pipelines, and release certification across long-horizon development sprints.

## Compounding structure

| Mandatory route | Conditional route | What the Mega layer adds |
|---|---|---|
| `autonomous-agent-foundry` | `capability-readiness` | Coordinates end-to-end execution of autonomous-agent-foundry with mission-level state gates. |
| `long-horizon-core` | `skill-forge` | Dynamically activates skill-forge based on mission requirements. |
| `long-horizon-core` | `automation-control` | Dynamically activates automation-control based on mission requirements. |
| `long-horizon-core` | `guarded-automation-loop` | Dynamically activates guarded-automation-loop based on mission requirements. |

## Route algorithm

1. Initialize mission state with `long-horizon-core` and load mission boundary parameters.
2. Evaluate `capability-readiness` for all required and conditional combo routes.
3. Execute primary pipeline via `autonomous-agent-foundry`.
4. Conditionally dispatch specialist combos based on runtime risk flags and telemetry.
5. Compile final verified deliverable into `AGENT_FOUNDRY_MISSION_RESULT.md` and persist immutable state.

## Durable state

`MISSION.md, ROADMAP.md, CONTEXT.md, EVIDENCE.md, HANDOFF.md` maintain durable mission state across sprints and server restarts.
