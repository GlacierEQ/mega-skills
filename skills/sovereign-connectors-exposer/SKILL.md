# SOVEREIGN-CONNECTORS-EXPOSER — Monolith Edition

**Repo:** GlacierEQ/computer-user

## Purpose
Make the entire external nervous system (connectors) visible, addressable, and mission-aligned. Produce and maintain a living ConnectorManifest.

## Activation
Any request to list, expose, health-check, or orchestrate connected services.

## Process
1. Call search_connected_tools (broad or targeted).
2. Categorize results (Notion, GitHub, Drive, Gmail, Supabase, Supermemory, Vercel, Box, etc.).
3. Optionally call health / whoAmI / list tools for critical connectors.
4. Synthesize ConnectorManifest (status, key tools, mission use).
5. Execute required actions via call_connected_tool.
6. Persist manifest or results into this monolith or Notion when useful.

## Output Contract
Structured manifest + live/degraded list + any executed actions + next exact task.
