# APEX DocGen Synthesis Mega Skill

## Mission

Orchestrate living architectural codex generation, AST docstring extraction, OpenAPI contract synthesis, and deterministic markdown receipt compilation across the entire APEX estate.

## Compounding structure

| Route Type | Member Combo Skill | What the Mega Layer Adds |
|---|---|---|
| **Mandatory** | `long-horizon-core` | Documentation mission framing, roadmap chunking, and living codex state tracking. |
| **Mandatory** | `architectural-refactoring-engine` | AST extraction, dependency boundary analysis, and codex topology synchronization. |
| **Conditional** | `capability-readiness` | Preflight tool & syntax validator vetting. |
| **Conditional** | `frontier-orbit-synthesis` | Portfolio-specific documentation, benchmark tables, and orbit mission packets. |

## End-to-end execution protocol

1. **Inspect AST & Signatures (`automated-documentation-synthesis`)**: Parse classes, methods, docstrings, and type hints from source.
2. **Map Architecture & Hierarchy (`automated-architecture-analysis`)**: Build topological diagrams and dependency graph documentation.
3. **Compile OpenAPI & API Schemas**: Synthesize endpoint contracts, JSON schemas, and payload examples.
4. **Synthesize Markdown Receipts**: Compile mission results and cryptographic test logs into `DOCGEN_SYNTHESIS_MISSION_RECORD.md`.

## Durable state

Maintains six immutable state files:
- `MISSION.md` — Documentation scope, audiences, and codex invariants.
- `ROADMAP.md` — Ordered documentation generation chunks.
- `EVIDENCE.md` — AST verification hashes and schema validation logs.
- `CONTEXT.md` — Lean active codex capsule.
- `HANDOFF.md` — Review and delivery checkpoint.
- `DOCGEN_RECEIPT.md` — Formal documentation delivery receipt.
