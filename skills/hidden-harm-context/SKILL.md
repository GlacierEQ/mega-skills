# Hidden Harm — Context Calibrator

> Chassis wheel. Governance polarity → `hidden-harm-governance` / `gate_polarity`. This skill owns semantic continuity; it does not invent permission ladders.

## Mission

Prevent context systems from silently changing what Casey meant, wanted, knew, corrected, prioritized, or intended. Context retrieval is useful only when it preserves semantic authority and materially constrains the next action.

## Protected Operator dimensions

Treat these as separately protected, never as one generic summary field:

- **word** — what Casey actually said
- **intention** — what Casey meant to accomplish
- **information** — firsthand facts, observations, and supplied context
- **strategy** — the route Casey intends to pursue
- **position** — the substantive stance Casey is taking
- **corrections** — explicit displacement of prior interpretations
- **scope and priority**
- **risk posture**

## Hidden harms to detect

1. **Authority substitution:** assistant summary, memory, task state, or provider metadata silently replaces Operator-authored meaning.
2. **Compression loss:** a concise memory drops motivation, distinctions, contradictions, strategy, or source pointers.
3. **Recency capture:** newest summary displaces stronger older source-bearing context without a true supersession.
4. **Retrieval-as-absence:** failed search or partial zero-result is treated as proof the fact never existed.
5. **Machine-state gravity:** `UNRESOLVED`, `OPEN`, `TODO`, `BLOCKED`, or `NEXT_FRONTIER` becomes a mission merely because it exists.
6. **Correction resurrection:** a displaced interpretation remains active after Casey corrected it.
7. **Matter contamination:** facts/strategies from one matter leak into another.
8. **Proof-project inversion:** verification work displaces the human objective even when the relevant truth is already sufficiently established for the next action.

## Operator-Intent Causality Test

Before acting on any derived state:

1. Which exact Operator objective/strategy/position does this serve?
2. What real outcome becomes closer?
3. Does the proposed action preserve Casey's actual words and distinctions?
4. Has Casey already answered, rejected, superseded, or deprioritized this concern?
5. Would following the machine state displace a stronger action Casey actually wants?

If the causal path is weak, preserve the metadata but do not elevate it into work.

## Execution

`RECOVER OPERATOR SOURCE -> RECOVER SUPPORTING CONTEXT -> PARTITION BY AUTHORITY DOMAIN -> RECONCILE WITHOUT COLLAPSE -> SCAN FOR SEMANTIC LOSS -> APPLY CURRENT CORRECTIONS -> SELECT OPERATOR-ALIGNED ACTION -> EXECUTE -> PRESERVE RICH CONTINUATION`

Use `RETRIEVAL_GAP` and `NO_MATCH_IN_PARTIAL_COVERAGE` instead of negative conclusions when coverage is incomplete.

## Success

Success means the next action is more faithful to Casey's actual intent and strategy than the compressed representation that routed to it. If a summary cannot preserve protected meaning, keep richer source pointers or split the representation instead of flattening it.
