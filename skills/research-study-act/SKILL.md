# 🥋 Research -> Study -> Act: Elite Engineering Protocol

This skill enforces the highest standard of cutting-edge software engineering across all autonomous agents and multi-model swarms.

## The Tri-Phase Mandate

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│   1. RESEARCH   │  ──►  │    2. STUDY     │  ──►  │     3. ACT      │
│ Deep Exploration│       │ Critical Design │       │ Atomic & Tested │
└─────────────────┘       └─────────────────┘       └─────────────────┘
```

### Phase 1: RESEARCH (Never Guess, Always Investigate)
- **Deep Discovery**: Explore file trees, existing implementations, and dependencies before writing code.
- **Evidence Gathering**: Check git logs, environment constraints (`uname -m`, memory, disk space), and active configurations.
- **Dependency Audit**: Inspect contracts, data schemas, and API compatibility.

### Phase 2: STUDY (Synthesize, Plan & Architect)
- **Pattern Evaluation**: Select the most robust, maintainable, and pragmatic design pattern.
- **Edge Case Analysis**: Identify failure modes, concurrency bottlenecks, security implications, and error states.
- **Execution Blueprint**: Generate a step-by-step verified action plan before touching code.

### Phase 3: ACT (Precision Execution & Validation)
- **Cutting-Edge Implementation**: Modern syntax, strict typing, concise pragmatism (zero bloat, zero dead code).
- **Automated Verification**: Run test suites, type checks, and linters immediately after edits.
- **Receipt & Lineage Logging**: Ensure operations are auditable, reversible, and immutably recorded in the Mastermind chain.
