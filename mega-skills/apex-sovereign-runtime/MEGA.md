# APEX Sovereign Runtime

## Mission

Unified control plane for native desktop embodiment, stacked multi-connector pipelines, automated self-healing, and absolute epistemic proof across local and cloud horizons.

## Compounding structure

- Required combos: `long-horizon-core`
- Conditional combos: `runtime-operations`, `epistemic-verification-chain`, `pipeline-orchestration`, `closed-loop-code-repair`, `capability-readiness`

## Execution protocol

1. Initialize `MISSION.md` through `HANDOFF.md` in the active execution workspace.
2. Execute required combos in deterministic dependency order.
3. Validate all intermediate evidence hashes and record telemetry in `EVIDENCE.md`.
4. Synthesize final mission deliverable `sovereign-runtime-mission-result.md`.
