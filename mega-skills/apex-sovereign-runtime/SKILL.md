1. Initialize the mission control plane with `long-horizon-core`, establishing `MISSION.md`, `ROADMAP.md`, and initial context boundaries.
2. Select `runtime-operations` when native macOS automation, screen perception, or application lifecycle supervision is required; verify that all desktop actions leave zero zombie processes.
3. Select `pipeline-orchestration` when data pipelines or stacked connectors (Supabase, GitHub API, OpenRouter, Google Drive, OneDrive) must be assembled into structured DAGs.
4. Route every generated artifact, code change, or factual claim through `epistemic-verification-chain` to ensure it meets or exceeds the $\mathcal{L}_2$ threshold before authorization.
