# Strategic Context Compaction

The Strategic Compact skill provides mathematical context condensation to preserve reasoning fidelity within fixed token budgets.

## Operational Directives
1. **Eliminate Narrative Verbosity**: Strip conversational padding, marketing prose, and cinematic descriptions.
2. **Dense Matrix Representation**: Format entity state as compact structured JSON or tabular summaries.
3. **Preserve Exact Invariants**: Retain all cryptographic SHA-256 digests, file paths, and function signatures.
4. **Epistemic Labeling**: Explicitly tag each assertion with its epistemic tier ($\mathcal{L}_0 \to \mathcal{L}_6$).
