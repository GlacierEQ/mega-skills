# APEX META SKILL KERNEL — Topology Specialist

**Repo:** GlacierEQ/computer-user  
**Role:** Skill-topology governor under `glaciereq-nervous-system`

## Authority Boundary

`glaciereq-nervous-system` owns cross-platform mission composition and continuation.

This skill owns:
- skill inventory and topology inspection;
- overlap and contradiction detection;
- stale projection detection;
- modularity and god-prompt-risk analysis;
- KEEP / REFACTOR / PROMOTE / MERGE / RETIRE recommendations;
- synchronization checks between canonical skills and host projections.

It does **not** redefine boot law, model selection, connector authority, Tower placement, execution completion, or the masterskill lifecycle.

## Activation Triggers
meta kernel, skill topology, drift detection, constellation maintenance, recursive improvement, new skill governance, cross-skill structural analysis, god-prompt risk, skill OS audit, projection drift.

## Process
1. Enter from `glaciereq-nervous-system` when topology work is required.
2. Ingest the current topology from `00_CONTROL_PLANE/SKILLS_REGISTRY.md`, the local `skills/` directory, and any current canonical skill sources.
3. Reconcile canonical skills versus host projections by source/commit where available.
4. Run contradiction, overlap, duplication, and stale-state scans.
5. Score critical topology risks.
6. Propose KEEP / REFACTOR / PROMOTE / MERGE / RETIRE with evidence-tagged rationale.
7. Persist the updated topology map and exact synchronization blockers.
8. Return control to the masterskill for execution, verification, and persistence across other planes.

## Output Contract
- Updated topology map (Markdown or JSON)
- Canonical/projection relationship map
- Drift/overlap findings
- Governance decision + score + verdict
- Patch recommendations or new skill skeleton when justified
- Exact continuation point

## Invariant
Keep skills modular. Do not solve topology problems by building a larger monolithic prompt. One authority per responsibility; projections preserve provenance.
