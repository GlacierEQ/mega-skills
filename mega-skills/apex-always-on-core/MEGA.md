## End-to-end execution protocol

1. **Preflight Estate Verification (`apex-boot-core`)**: Audit POSIX binary permissions (`0o755`), runtime versions, and MCP gateway reachability.
2. **Sequential Cognitive Framing (`chunk-power`)**: Chunk initial user mandate into discrete, bounded micro-steps with explicit hypothesis generation and confidence scoring.
3. **Context Economy Optimization (`token-saver`)**: Compact prompt packs and prune redundant conversational history into lean active capsules.
4. **Multi-Service Connectivity Binding (`aspen-grove-connectors`)**: Resolve credentials dynamically, enforce backoff policies, or bind sandboxed mock adapters.
5. **Adversarial Swarm Dialectic (`make-it-heavy`)**: Execute 4-phase dialectic consensus across Reasoner, Synthesizer, Auditor, and Perception roles.
6. **Cognitive Synthesis Gate**: Synthesize branch hypotheses into an evidence-backed action plan before triggering mutations.
7. **Fail-Closed Release Gate (`quality-gate`)**: Enforce cryptographic SHA-256 validation across all artifacts before sealing delivery into `ALWAYS_ON_CORE_MISSION_RESULT.md`.
